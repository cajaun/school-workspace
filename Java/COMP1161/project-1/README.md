# COMP1161 Project 1

Project 1 models a Department of Security and its response to crime reports across communities. The source defines communities, residents, criminals, operations, and security responses.

## Runtime Shape

~~~text
Driver.java
    |
    +--> testData2.txt
    +--> DoS and community model
    +--> operations and public reports
~~~

`Driver` reads `testData2.txt` through a relative path. Run the program from this folder so the input file resolves correctly.

## Build and Run

~~~bash
javac *.java
java Driver
~~~

The folder also keeps `testData.txt`, `testData2.txt`, `testData3.txt`, and `testData4.txt`, the BlueJ project file, compiled class files, and a submitted ZIP archive.
