# COMP3220

This course folder contains the Maze Lab search application and the heart disease prediction project.

## Assignments

| Assignment | Scope | Guide |
| --- | --- | --- |
| Assignment 2 | Interactive maze solving with BFS, DFS, and A* | [assignment README](assignment-2/README.txt) |
| Assignment 4 | Heart disease classification, model comparison, and Kaggle predictions | [assignment README](assignment-4/README.md) |

## Local Development

Run each assignment from its own folder so its imports, assets, datasets, and output files resolve correctly.

The maze project uses Tkinter and Pillow. The prediction project uses Jupyter, pandas, scikit-learn, and the packages listed in its local `requirements.txt`.
