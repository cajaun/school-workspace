# COMP2190

This course folder contains two networked cryptography projects.

| Project | Scope | Guide |
| --- | --- | --- |
| Project 1 | Diffie-Hellman-style key exchange and a client-server protocol | [project 1](project-1/README.md) |
| Project 2 | RSA key exchange, simplified AES, nonce verification, and encrypted messages | [project 2](project-2/README.md) |

Both projects use local TCP sockets. Start the server before the client and use a port above 1023.
